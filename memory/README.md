# Memória do Atlas

A memória permanente será organizada por categorias:

- Perfil do proprietário
- Objetivos
- Projetos
- Empresas
- Clientes
- Funcionários
- Investimentos
- Estudos
- Conversas
- Decisões
- Documentos
- Aprendizados
- Rotinas
- Ideias
- Conhecimento Técnico

Nenhuma informação importante deve depender apenas de uma conversa temporária.
